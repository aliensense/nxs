# Contributing

Development of the NXS SDK happens in an internal tree that also holds the
device firmware, so wire-format changes land on both sides in one change.
This repository is the released source: every NXS release exports the SDK
here, tagged with the product version.

What that means in practice:

- **Issues are welcome here.** Bug reports, feature requests, and questions
  are triaged in this repository.
- **Pull requests are reviewed here, applied internally.** An accepted patch
  is imported into the internal tree with attribution and ships in the next
  release. Direct merges to this repository would be overwritten by the next
  export.
- **Releases carry the changes.** There is no development branch to track;
  `main` always reflects the latest release.

## Building and testing

```sh
pip install -e '.[cyphal]'
nxs --version
```

The tests live in the private repository and run there without hardware; a
standalone checkout is checked with the two commands above. Driver files under
`nxs/drivers/` are generated by the driver-generation skill
(`skills/nxs-generate-sensor-personality/`) and validated on hardware; regenerate
rather than hand-edit them.
